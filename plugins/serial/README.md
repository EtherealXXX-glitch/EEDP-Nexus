# 串口组件 v1.1

契约遵循工作台 `COMPONENT-STANDARD.md`。使用原生 serial 视图，Agent 使用 `serial.*` / `serial__*`。

ports/status 只读；connect 会打开串口及设置 DTR/RTS，send 会发送实际字节，均标为破坏性操作。
桌面端口列表显示系统返回的设备描述（例如 CH340），选择时仍使用原始 COM 端口号；设备名称以驱动实际报告为准。
disconnect 释放当前组件的端口，不关闭其他软件。连接前查询全局资源占用。

pyserial 接收线程将原始 RX/TX 以 Base64 写入共享 Activity，同时保留增量解码文本。
连接参数记忆，普通发送草稿不记忆。桌面可显式保存、载入和删除命名常用命令，预设包含内容、HEX 模式和结尾；载入后须手动发送。左侧发送设置提供命令行模式、HEX 发送和结尾选项，前两者互斥。文本结尾支持 CRLF（默认）、CR、LF、NONE；HEX 发送只发送输入字节，不追加结尾。恢复设置不自动连接、不重放指令。关闭主窗口不停止接收。
禁用前须 disconnect；组件 close 负责停止线程及释放资源。库依赖为发行版内置 pyserial。
# 波特率

桌面下拉框提供 35 个常见及高速预设（110–12000000，含 96000），支持手动输入。Agent 的 `connect.baudrate` 同样接受整数，不受桌面预设限制；实际支持范围取决于串口硬件和驱动，打开失败会返回错误并释放占用。
