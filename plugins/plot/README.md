# 数据波形

每行以 `@plot ` 开头，后接逗号分隔的 `名称=数值`，例如：

```text
@plot temperature=23.5,voltage=3.30
@plot temperature=23.7,voltage=3.29
```

名称以英文字母或下划线开头，后接字母、数字或下划线，最多 32 个字符；数值为绝对值不超过 1e100 的有限数字。最多 16 个通道，清空波形后可重新使用其他名称；行尾使用 LF 或 CRLF。非 `@plot ` 行被忽略；数据可分多次输入，直到行结束才解析。最多保留最近 5000 个数据点。组件不连接串口、不自动启动硬件操作。

打开“数据波形”后，界面读取现有串口接收事件并绘制多条曲线。横轴是数据点序号；滚轮平移，Ctrl+滚轮缩放。CLI/MCP 可通过 `plot.feed` / `plot__feed` 输入，`samples` 读取，`clear` 清除；这些动作不访问设备。
